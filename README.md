# biotecnologia-certificado-bioinformatica-ciencia-datos
Este repositorio es para las asignaturas del certificado de extensión en bioinformatica y ciencia de datos´de biotecnologia en la UCV.


Acabo de subir una carpeta llamada proyectos_biotec, dentro de la cual encontramos 5 subdirectorios distintos, llamados datos_crudos, datos_procesados, documentacion, scripts y resultados. Dentro de cada una podemos encontrar diferentes archivos de texto plano completamente vacíos llamados informe_datos.txt, documentos_laboratorio.txt, mis_resultados_finales.txt y analisis_datos_script.txt. También hay algunos que sí tienen contenido, como conceptos_clave.txt, historial_comandos_B.txt e historial_comandos_C.txt. Asimismo, dentro de datos_curiosos encontramos una copia del directorio fcb_material_practica1 proporcionado por el docente.
